Fonctionnalités clés

Achat automatique

Processus en 1 étape: le client choisit, paie et reçoit son code instantanément. Le backend achète automatiquement sur les sites officiels.

Paiement en TND

Prix transparent = Prix original converti en Dinars Tunisiens + 15% commission. Aucune conversion complexe.

Facture automatique

Email de confirmation avec facture détaillée, code de confirmation et instructions de livraison.

Auto-discovery

Scan automatique quotidien des promotions et tendances. Import en 1 clic depuis le panel admin.

Comptes fournisseurs

Configuration des comptes internationaux (Netflix, Spotify, etc.) pour achat automatique depuis le panel admin.

Dashboard complet

Stats en temps réel, gestion produits/commandes/utilisateurs, configuration paiement.

Installation locale

# Cloner le projet
git clone https://github.com/HiTech-Business-Club/HiTechStore.git

# Accéder au projet
cd hitechstore-v4/backend

# Installer les dépendances
npm install

# Initialiser la base de données
npm run seed

# Démarrer le serveur
npm start

Store: http://localhost:3000
Admin: http://localhost:3000/admin
