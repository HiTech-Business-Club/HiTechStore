Plateforme e-commerce tunisienne pour services numériques internationaux. Achat automatique, paiement en TND, livraison instantanée.

Aperçu de l'application

Store Client

Design moderne futuriste avec glassmorphism. Navigation par catégories, filtres, achat en 1 clic.

Panel Admin

Dashboard complet, gestion produits/commandes/utilisateurs, configuration fournisseurs.

Achat Automatique

Checkout simplifié. Le backend achète automatiquement sur les sites officiels.

Fonctionnalités principales

Achat automatique 1 étape

Le client choisit, paie et reçoit son code instantanément

Paiement en TND

Prix = Prix original + 15% commission, le tout en Dinars Tunisiens

Email automatique avec facture

Confirmation détaillée avec code de confirmation et facture

Auto-discovery des tendances

Scan automatique quotidien des promos et tendances

Gestion des fournisseurs

Configuration des comptes internationaux pour achat auto

Installation locale

# Cloner le projet
git clone https://github.com/HiTech-Business-Club/HiTechStore.git

# Installer les dépendances
cd hitechstore-v4/backend
npm install

# Seed et démarrage
npm run seed
npm start
